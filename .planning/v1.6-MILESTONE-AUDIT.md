## What changed since the first audit

- **Live tag failure fixed.** Root cause (proven by live `[TAG-DEBUG]` logs): a layer-224
  connection on the shared session upgraded the session to layer 224 server-side, so the main
  client's `GetParticipant` responses came back unparseable (`TypeNotFoundError` → misclassified
  `NETWORK`). Fixed via two-phase layer isolation in `TagExecutor` (Phase A reads at 198 → Phase B
  writes at 224 → Phase C restore to 198). **User-confirmed working live** for the write path.
- **Nyquist tech-debt closed.** All four phases now `nyquist_compliant: true` (119 tag tests green).
- **Renderer copy fixed.** `rowError` strings rewritten (en+cs) — accurate, no dangling fragments;
  queued-row aria corrected.
