    - Click "Česky" — menu closes and entire app switches to Czech instantly (no reload, no flash)
    - Walk through every screen: Settings menu labels, auth flow (if logged out: PhoneStep/CodeStep/PasswordStep labels), GroupsPane (empty states, scan progress, group rows), wizard (step indicator, Review screen, run trigger button, confirm button, report)

    - In Czech mode, navigate to a state showing group counts

    - Verify: 5+ groups → "5 skupin" (not "5 skupina" or "5 skupiny")

    Step 3 — Theme toggle:
    - Settings gear → Theme section → click "Denní" (Day) — app switches to light colors instantly
    - Settings gear → click "Noční" (Night) — app switches back to dark
    - Verify active theme has checkmark; inactive has w-4 placeholder (no label shift between selections)

    Step 4 — Persistence on relaunch (LOC-01):
    - Set language to Czech and theme to Day
    - Quit the app (Cmd+Q or close window)
    - Relaunch — verify first paint shows Czech AND Day (light) theme with zero flash of wrong state
    - Verify the settings menu correctly shows "Česky" and "Denní" as active

    Step 5 — nativeTheme interplay:
    - With Day theme selected in app, toggle macOS system appearance (System Preferences → Appearance → Dark)

    - Toggle macOS back to Light; app should still be in Day theme (no change)

    Step 6 — Safety gates:
    - Verify "English" label in the Language section never changes to "Anglicky" or any Czech form — it must stay "English" in both locales (standard locale-picker convention)
    - Verify "Česky" label stays "Česky" in both locales
    - Verify no Telegram error codes appear as raw user-readable text in either language (e.g., "FLOOD_WAIT" must not appear without surrounding translated context)
