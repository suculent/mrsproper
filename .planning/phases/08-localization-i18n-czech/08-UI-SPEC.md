## Typography

Unchanged from Phase 1 contract — exactly 4 sizes, 2 weights (Inter 400 + 600):

| Role | Size | Weight | Line Height | Phase 8 usage |
|------|------|--------|-------------|---------------|
| Body | 16px | 400 | 1.5 | (unchanged elsewhere) |
| Label | 14px | 600 | 1.5 | Menu section headers ("Language"/"Jazyk", "Theme"/"Motiv") in `text-muted-foreground` |
| Heading | 20px | 600 | 1.2 | (unchanged) |
| Display | 28px | 600 | 1.2 | (unchanged) |

Menu option rows (English, Česky, Day/Denní, Night/Noční, Log out/Odhlásit se): **`text-sm` (14px) weight 400** — matches the existing "Log out" row exactly.

**Czech text-expansion rule (applies app-wide, enforced during translation):** no fixed-width buttons or truncating labels for translated copy. Buttons size to content (`w-auto`/flex); the only permitted truncation is on dynamic Telegram data (group names), which is never translated. Czech runs ~10–25% longer than English; the Review-screen confirm CTA and GroupsPane run-trigger must wrap or grow, never clip.

This phase introduces NO new color values. The "Day" theme = the **already-defined `:root` light tokens** in globals.css (written in Phase 1, currently unreachable because theme is nativeTheme-driven). "Night" = the existing `.dark` tokens.

### Night (existing `.dark`)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0B1220 (`--background`) | App background, surfaces |
| Secondary (30%) | #1E293B slate-800 (`--secondary` / `--popover` #1E293B) | Shell chrome, popover/menu, inputs |
| Accent (10%) | #3B82F6 blue-500 (`--primary`) | See reserved list |
| Destructive | #EF4444 red-500 | Destructive actions only (Log out row, Ban semantics) |

### Day (existing `:root`, activated by this phase)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFFFFF (`--background`) | App background, surfaces, popover |
| Secondary (30%) | #F1F5F9 slate-100 (`--secondary`) | Shell chrome, sidebar regions |
| Accent (10%) | #2563EB blue-600 (`--primary`) | See reserved list |

Accent reserved for (unchanged from Phase 1, no additions): primary/submit buttons, focus ring, resend link. **The active-option checkmark in the Settings menu uses `text-foreground`, NOT accent** — selection state is not a call to action; this protects the 10% accent budget.

## Component Contract: SettingsMenu Rework

Extend `src/renderer/shell/SettingsMenu.tsx` (custom dropdown, backdrop-close pattern retained). Final menu structure top-to-bottom:

```
┌──────────────────────────────┐  min-w-[200px], rounded-md, border,
│ Language            (header) │  bg-popover, shadow-md, py-1
│   English                ✓   │
│   Česky                      │
│ ──────────────────────────── │  separator: border-t border-border, my-1
│ Theme               (header) │
│   ☀ Day                      │
│   ☾ Night               ✓   │
│ ──────────────────────────── │
│ Log out                      │  (existing destructive row, unchanged style)
└──────────────────────────────┘
```

| Element | Spec |
|---------|------|
| Section headers | `text-label` role at `text-sm font-semibold` is too heavy inside a menu — use **14px / 600 / `text-muted-foreground`**, `px-3 pt-2 pb-1`, non-interactive (`role="presentation"`) |
| Option rows | `<button role="menuitemradio" aria-checked={active}>`, full-width, `px-3 py-2 text-sm`, flex row with `justify-between items-center` |
| Active indicator | lucide `Check` `h-4 w-4 text-foreground`, right-aligned; absent (not invisible-placeholder) on inactive rows is NOT allowed — reserve the slot with `w-4` so labels don't shift on switch |
| Theme icons | lucide `Sun` / `Moon` `h-4 w-4 text-muted-foreground mr-2`, left of label, `aria-hidden` |
| Language option labels | **Always self-named, never translated**: "English" stays "English" and "Česky" stays "Česky" in BOTH locales (standard locale-picker convention — a user lost in the wrong language must find their own) |
| Menu container | `role="menu"`, `aria-label` translated ("Settings menu" / "Nabídka nastavení") |
| Keyboard | Rows are native `<button>`s — Tab/Enter work; no custom focus-trap required (matches existing menu) |

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Select language | Persist via `LANGUAGE_SET` IPC → `i18n.changeLanguage()` → entire tree re-renders instantly. **Menu closes on selection** (whole-app language flip is the feedback; keeping the menu open shows stale-language chrome around it). No restart, no reload dialog. |
| Select theme | Persist via `THEME_SET` IPC → toggle `document.documentElement.classList` `dark` class. **Menu closes on selection.** Instant swap, no CSS transition animation on the root swap (avoid 200ms full-tree color tween artifacts). |
| First launch (language) | No stored pref → OS locale `cs*` → Czech, else English. Stored pref always wins thereafter. |
| First launch (theme) | No stored pref → follow `nativeTheme` (current behavior). Once the user picks Day or Night, the stored choice **overrides nativeTheme permanently** — the existing main-process `nativeTheme.on('updated')` push must not clobber an explicit user choice. |
| Pre-mount init | Both language and theme are fetched via IPC **before React mounts** (same pre-mount pattern as severity) — zero flash of wrong language and zero flash of wrong theme on launch. |
| Selecting already-active option | No-op (no persist round-trip needed), menu closes. |

**State coverage:** there is no loading/empty/error UI for the switcher itself — IPC get/set on local electron-store is effectively synchronous. If `LANGUAGE_GET`/`THEME_GET` fails, fall back to detection defaults silently (never block app mount on a pref read).

## i18n Resource Contract

| Rule | Spec |
|------|------|
| Namespaces | `auth`, `target`, `groups`, `wizard`, `removal`, `shell` — one JSON per namespace per locale, eager-bundled (small app, offline constraint; no lazy loading) |
| Key naming | Mirror existing copy-module property names: `wizardCopy.reviewTitle` → `wizard:reviewTitle`; nested objects keep nesting (`wizard:stageLabel.target`) |
| Plurals | i18next suffixes. English: `_one`/`_other`. Czech: `_one`/`_few`/`_other` ("1 skupina / 2 skupiny / 5 skupin"). The English-only `s()` helper in wizardCopy.ts is replaced by plural keys — **no string-concatenation pluralization survives migration** |
| Interpolation | i18next `{{name}}` placeholders; React escaping left at react-i18next defaults (`escapeValue: false` is the documented react-i18next setting since React escapes) |
| Never translated | Telegram data: group names, usernames, target identity, numeric IDs, raw Telegram error codes (`FLOOD_WAIT`, `PEER_FLOOD`). Codes appear verbatim inside translated sentences |
| Register | Formal vykání throughout Czech copy ("Potvrďte…", "Vraťte se…") |
| Post-migration | All six `*Copy.ts` modules deleted; components use `useTranslation()`. No hardcoded user-facing string in any component (LOC-02) |

## Copywriting Contract

Key strings in both locales (vykání register; action verbs locked by CONTEXT.md). This table is the canonical reference for the new/changed surfaces; full translation happens per-namespace during execution under these rules.

| Element | English | Czech |
|---------|---------|-------|
| Menu: language header | Language | Jazyk |
| Menu: language options | English / Česky | English / Česky (self-named, identical in both locales) |
| Menu: theme header | Theme | Motiv |
| Menu: theme options | Day / Night | Denní / Noční |
| Menu: log out (existing) | Log out | Odhlásit se |
| Settings tooltip / aria | Settings | Nastavení |
| Primary CTA (wizard confirm, severity=ban) | Ban {{name}} from {{count}} group(s) | Zabanovat {{name}} — {{count}} skupina / 2–4 skupiny / 5+ skupin (plural forms via `_one/_few/_other`) |
| Primary CTA (wizard confirm, severity=kick) | Kick {{name}} from {{count}} group(s) | Vyhodit {{name}} — plural forms as above |
| Severity labels | Kick / Ban | Vyhodit / Zabanovat |
| Empty state (no groups selected) | No groups selected — go back and check at least one group. | Nejsou vybrány žádné skupiny — vraťte se a zaškrtněte alespoň jednu skupinu. |
| Error state pattern | {problem} + {next step}, Telegram code verbatim. e.g. "Telegram asked us to wait (FLOOD_WAIT). The run resumes automatically in {{s}} s." | "Telegram požádal o čekání (FLOOD_WAIT). Akce bude automaticky pokračovat za {{s}} s." |
| Destructive confirmation (existing gate, translated) | Review screen + one explicit confirm button (SAF-02) | Same gate; confirm copy uses the CTA forms above — destructive verb first, target name, exact group count |

Copy rules carried into every translated namespace:
1. Destructive buttons name the action and the scope ("Zabanovat X — 5 skupin"), never a bare "OK/Potvrdit".
2. Error copy = what happened + what to do next; Telegram codes never translated, always parenthesized verbatim.
3. No exclamation marks; calm admin-tool tone in both languages.
