    Behavioral contract (what tests assert):

    getState():
    - Returns current _currentState (initially idle shape).

    abortExecution():
    - Increments _generation, calls _abortController.abort() if non-null.
    - When step is NOT 'running'/'stopping': emits idle shape immediately.
    - When step IS 'running': does NOT emit; execute() loop detects gen increment and emits 'stopped'.

    _handleGovernorEvent(event):
    - No-op when _runActive is false.
    - When _runActive is true and event.type === 'flood-tick': emits { ...currentState, floodWaitRemaining: event.remaining }.

    execute({ dialogIds, tag }):
    - Guard: resolver.getResolvedUser() null → emit idle, return.
    - Guard: enumerator.getState().step !== 'loaded' → emit idle, return.
    - Calls tagClient.connect() AFTER early-exit guards pass.
    - Wraps main loop in try/finally { await tagClient.disconnect() } — disconnect on ALL terminal paths.
    - Calls auditStore.initJob() with TagJobFile schema.
    - For each dialog in selectedDialogs:
      * Generation guard #1 (top of loop): if gen !== _generation || signal.aborted → mark remaining skipped, setStatus('stopped'), emit stopped, return.
      * Calls _tagGroup(dialog, resolved, tag).
      * On PEER_FLOOD (hard-stop): setStatus('hard-stopped'), emit hard-stopped, return (remaining NOT marked skipped — resumable).
      * Generation guard #2 (BEFORE checkpoint): if stale → mark remaining skipped, emit stopped, return.
      * auditStore.checkpoint(dialog.id, outcome).
      * outcomes.push(outcome).
      * Sleep 2000 + Math.random() * 1000 ms (inter-group pacing).
      * Generation guard #3 (after pacing).
    - Generation guard #4 (post-loop, before complete): if stale → return silently.
    - auditStore.setStatus('complete', completedAt); emit complete.

    _tagGroup(dialog, resolved, tag) — private:
    - If dialog.type === 'basic-group': return skipped + TAG_UNSUPPORTED_BASIC_GROUP (no API call).
    - Build InputPeerChannel from enumerator.getDialogEntity(dialog.id); InputPeerUser from resolved.
    - Call governor.run(() => mainClient.invoke(GetParticipant)) for already-admin check.
    - If participant.className === 'ChannelParticipantAdmin': return skipped + TAG_TARGET_IS_ADMIN (no tagClient call).
    - Call await tagClient.invoke(makeEditChatParticipantRankRequest(inputPeer, inputUser, tag)).
      NOTE: do NOT wrap in governor.run() — tagClient.invoke() is already governor-wrapped (Pitfall 3).
    - Return { dialogId, status: 'done', timestamp }.

    _classifyTagError(err, dialogId) — private:
    - CRITICAL: re-throw if classifyRpcError(err).disposition === 'hard-stop' (Pitfall 1 — PEER_FLOOD must bubble to execute() catch).

    - USER_NOT_PARTICIPANT | USER_ID_INVALID → TAG_USER_INVALID.
    - CHANNEL_PRIVATE → TAG_CHANNEL_INVALID.
    - classifyRpcError NETWORK disposition → NETWORK.
    - Anything else → UNKNOWN.
    - NOTE: TAG_USER_NOT_PARTICIPANT, TAG_RANK_INVALID, TAG_CHANNEL_PRIVATE are NOT valid TagErrorCode values.

    _buildSummary(outcomes, completedAt):
    - Returns { tagged: count(done), skipped: count(skipped), failed: count(failed), completedAt }.
    - Field is 'tagged' (not 'removed'); no 'alreadyGone' concept.
