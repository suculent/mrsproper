UI-SPEC row ordering (D-01):
- Partition dialogs into actionable (canAct=true) and non-actionable (canAct=false)
- Within actionable: sort A-Z by title (default) or descending memberCount
- Within non-actionable: same sort
- In checklist mode: further filter actionable to canAct && status=member; non-actionable includes canAct=false rows AND canAct=true rows where status=not-member (user is not a member there)

UI-SPEC interaction (D-06): checklist is interactive during scan — a row is actionable if canAct=true AND (status='member' OR (status=null AND scan.step==='scanning')). Wait: status null = pending. Pending rows show the scan-pending skeleton (plan 07 GroupRow handles this). toggleGroup should only be enabled for rows with status='member'.

Scan progress (D-05): render `<div role="status" aria-live="polite">` wrapper containing: "Scanning your groups..." label + "checked N / M" counter (both from SCAN_COPY) + thin progress bar `<div className="h-1 bg-muted rounded-full overflow-hidden"><div className="h-full bg-primary transition-[width]" style={{ width: \`${(checked/total)*100}%\` }} /></div>`.

Sort toggle (D-01): `type SortMode = 'az' | 'size'`; local state `const [sort, setSort] = useState<SortMode>('az')`.

Browse-mode filter: `const [filter, setFilter] = useState('')`; filter function: `dialog.title.toLowerCase().includes(filter.toLowerCase())`.

    Imports: React, useState; useGroupsStore, groupsActions from '../store/groupsStore'; useTargetStore from '../store/targetStore'; ScrollArea from '../components/ui/scroll-area'; GroupRow from './GroupRow'; Input from '../components/ui/input'; Button from '../components/ui/button'; Search icon from 'lucide-react'; RefreshCw icon from 'lucide-react'; AdminDialogDTO, MembershipStatus, MembershipResultDTO from '@shared/groupTypes'; all needed exports from './groupsCopy'.

    Local state: `const [sort, setSort] = useState<'az' | 'size'>('az')` and `const [filter, setFilter] = useState('')`.

    Store consumption: `const { groups, scan, checkedDialogIds } = useGroupsStore()` and `const targetState = useTargetStore()`.

    Mode derivation: `const mode = targetState.target.step === 'confirmed' ? 'checklist' : 'browse'`.

    Helper `getMembershipStatus(dialogId: string): MembershipStatus | null`: if scan.step === 'scanning' or scan.step === 'complete', find result in scan.results; return result.status ?? null. If scan.step is idle/error, return null.

    Helper `sortDialogs(dialogs: AdminDialogDTO[])`: if sort === 'az', sort by title.localeCompare; if sort === 'size', sort by (memberCount ?? -1) descending.

    Browse mode dialog list: filter `groups.step === 'loaded' ? groups.dialogs : []` by `filter === '' || title.toLowerCase().includes(filter.toLowerCase())`. Apply sortDialogs. Include all dialogs (no membership filter in browse mode).

    Checklist mode dialog list: take `groups.step === 'loaded' ? groups.dialogs : []`; derive `results = scan.step === 'scanning' || scan.step === 'complete' ? scan.results : []`; partition into `actionable` (canAct=true, status=member OR pending-during-scan) and `nonActionable` (canAct=false OR status=not-member); sort each partition; concatenate actionable first.

    For checklist mode: when target just confirmed and scan is idle, trigger scan automatically. Use useEffect: `useEffect(() => { if (mode === 'checklist' && scan.step === 'idle') { void groupsActions.startScan() } }, [mode])`.

    When mode changes to browse (target reset/change), abort any in-progress scan: `useEffect(() => { if (mode === 'browse' && (scan.step === 'scanning')) { void groupsActions.abortScan() } }, [mode])`.

    Toolbar (rendered outside ScrollArea, sticky top):
    `<div className="flex items-center gap-2 p-4 shrink-0 border-b border-border">`
    - Browse mode: `<div className="relative flex-1"><Search className="absolute left-2.5 top-2.5 h-4 w-4 text-muted-foreground" /><Input placeholder="Filter groups" value={filter} onChange={e => setFilter(e.target.value)} className="pl-8" /></div>`
    - Sort toggle button (both modes): `<Button variant="ghost" size="sm" onClick={() => setSort(s => s === 'az' ? 'size' : 'az')} aria-pressed={sort === 'size'}>{sort === 'az' ? 'A–Z' : 'By size'}</Button>`
    - Refresh button: `<Button variant="ghost" size="icon" onClick={() => void groupsActions.refreshGroups()} aria-label="Refresh group list" title="Re-fetch your group list from Telegram"><RefreshCw className="h-4 w-4" /></Button>`
    Toolbar close.

    Scan progress (checklist mode, inside scan.step === 'scanning'):
    `<div className="px-4 py-2 shrink-0" role="status" aria-live="polite">`
    `<div className="flex items-center justify-between mb-1">`
    `<span className="text-label text-muted-foreground">{SCAN_COPY.scanning}</span>`
    `<span className="text-label font-semibold text-foreground">checked {scan.progress.checked} / {scan.progress.total}</span>`
    `</div>`
    `<div className="h-1 bg-muted rounded-full overflow-hidden"><div className="h-full bg-primary transition-[width] duration-200" style={{ width: \`${scan.progress.total > 0 ? Math.round(scan.progress.checked / scan.progress.total * 100) : 0}%\` }} /></div>`
    `</div>`

    Failed summary (checklist mode, scan complete, some failed):
    Count `failedCount = scan.step === 'complete' ? scan.results.filter(r => r.status === 'failed').length : 0`.
    If failedCount > 0: `<p className="px-4 py-1 text-label text-muted-foreground">{SCAN_COPY.failedN(failedCount)}</p>`.

    Group list (ScrollArea wrapping the rows):

    `<div className="divide-y divide-border">`
    Render GroupRow per dialog in the sorted/filtered list. Pass: `dialog`, `membershipStatus={getMembershipStatus(dialog.id)}`, `isChecked={checkedDialogIds.has(dialog.id)}`, `onToggle={groupsActions.toggleGroup}`, `onRetry={dialogId => void groupsActions.retryScanGroup(dialogId)}`.
    `</div>`
    `</ScrollArea>`

    Empty states (inside the ScrollArea-equivalent area when list is empty):
    - Browse, groups.step === 'loaded' and filtered list empty and filter non-empty: EMPTY_STATE_COPY.noMatches
    - Browse, groups.step === 'loaded' and total list empty: EMPTY_STATE_COPY.noGroups

    - Browse, groups.step === 'error': `<p className="px-4 py-4 text-label text-muted-foreground">{GROUP_ERROR_COPY[groups.code]}</p>`
    - Checklist, scan complete and no member rows: EMPTY_STATE_COPY.notInAny(targetName) where targetName is read from `targetState.target.step === 'confirmed' ? targetState.target.dto.name : ''`
