    Constructor private fields: _client, _governor, _enumerator, _resolver, _auditStore, _emit, _currentState: RemovalState, _generation = 0, _abortController.

    execute(params: { severity: 'kick' | 'ban', dialogIds: string[] }): Promise<void>
    - Increment _generation; create AbortController; capture gen = this._generation
    - Get resolver.getResolvedUser() — if null, emit error state, return
    - Get enumerator.getState() — if not 'loaded', emit error state, return
    - Filter enumerator dialogs to those in params.dialogIds (preserve order)
    - initJob on auditStore with full job file
    - Loop over filtered dialogs:
      - gen guard (gen !== this._generation || signal.aborted): mark remaining skipped, checkpoint all, emit stopped, return
      - emit step='running', currentGroupId=dialog.id
      - try: call _removeFromGroup(dialog, resolved, severity)
      - catch (err): _classifyRemovalError(err) — if hard-stop, auditStore.setStatus('hard-stopped'), emit hard-stopped, return (do NOT mark remaining skipped)
      - gen guard BEFORE checkpoint (Pitfall 7: if gen changed during await, skip checkpoint and return)
      - auditStore.checkpoint(dialog.id, outcome)
      - inter-group pacing: await sleep(2000 + Math.random() * 1000)
      - gen guard after pacing
    - After loop: auditStore.setStatus('complete', new Date().toISOString()), emit step='complete' with summary

    _removeFromGroup(dialog, resolved, severity): dispatches by dialog.type:
    - 'basic-group': construct InputPeerUser from resolved.id+accessHash (bigInt); construct chatId from entity.id or dialog.id; call governor.run(() => client.invoke(new Api.messages.DeleteChatUser({ chatId, userId: inputUser }))); return { status: 'done', note: severity==='ban' ? 'basic-group-ban-fallback' : null, dialogId: dialog.id, timestamp: now }
    - 'supergroup' | 'broadcast-channel': extract entity id+accessHash via getDialogEntity() (duck-typed per PATTERNS.md line 177); construct InputChannel and InputPeerUser; if ban: single EditBanned call; if kick: EditBanned(restrict) → sleep(500) → EditBanned(unban, empty rights); return { status: 'done', note: null, dialogId, timestamp }
    - Unknown type: throw Error (defensive)

    _classifyRemovalError(err): check errorMessage:
    - 'USER_NOT_PARTICIPANT': return { status: 'already-gone', dialogId: '', timestamp: now }
    - 'USER_ADMIN_INVALID': return { status: 'failed', errorCode: 'RMV_TARGET_IS_ADMIN', dialogId: '', timestamp: now }
    - 'CHAT_ADMIN_REQUIRED': return { status: 'failed', errorCode: 'RMV_NO_RIGHTS', ... }
    - 'USER_ID_INVALID': return { status: 'failed', errorCode: 'RMV_USER_INVALID', ... }
    - 'CHANNEL_PRIVATE': return { status: 'failed', errorCode: 'RMV_CHANNEL_PRIVATE', ... }
    - else: call classifyRpcError(err); if disposition='hard-stop', re-throw err (outer catch handles PEER_FLOOD); else return { status: 'failed', errorCode: 'UNKNOWN', ... }

    abortExecution(): void
    - Increment _generation; abort the AbortController; mark all non-checkpointed groups as skipped in auditStore; emit step='stopped'

    retryGroup(dialogId: string): Promise<void>
    - Require current state step === 'complete' or 'stopped'
    - Capture gen = this._generation BEFORE async gap (CR-02)
    - Re-run _removeFromGroup for this single dialog
    - Gen guard AFTER await, BEFORE updating state (CR-02)
    - Update outcomes array in current state; re-emit

    getState(): RemovalState — returns _currentState
