<task type="checkpoint:human-action" gate="blocking">
  <what-built>
    Version 0.9.0 RC artifacts are in release/dist/ and passed dev-machine Gatekeeper verification (Plan 04). The artifacts are ready for distribution to the four verification machines.

    Artifact selection guide (from RESEARCH.md Finding 5):
    - ARM Mac (Apple Silicon): MrsProper-0.9.0-arm64.dmg
    - Intel Mac: MrsProper-0.9.0.dmg (no arch suffix)
    - Big Sur Mac: Use the matching arch DMG for that machine's CPU. If arch unknown, try arm64 first (Apple Silicon Macs are more common); if that fails, use x64. Both Electron 37 arches carry LSMinimumSystemVersion: 11.0.
    - Windows VM: MrsProper Setup 0.9.0.exe (NSIS installer) OR MrsProper-0.9.0-portable.exe

    Transfer method (D-10): Direct share via Drive/Telegram/USB — no hosted download page.
  </what-built>
  <how-to-verify>
    Distribute the artifacts and run the smoke test on each machine. The smoke test per machine is:

    macOS machines (ARM Mac, Intel Mac, Big Sur Mac):
    1. Copy the correct DMG to the machine via Drive, Telegram, or USB (it will have the quarantine xattr from download, which is the real Gatekeeper test condition)
    2. Double-click the DMG to mount it
    3. Drag "Mrs. Proper" to Applications
    4. Open Mrs. Proper from Applications
    5. EXPECTED: App opens directly — no Gatekeeper dialog, no "this app is damaged", no "requires macOS 12" system alert
    6. Telegram login screen appears → enter any phone number → tap "Send code"
    7. EXPECTED: Login code input screen appears (proves embedded api_id/api_hash is live)
    8. Close/quit the app (do not complete login with real credentials unless you want to)

    Big Sur-specific check:
    - The app must open without any system dialog saying "requires macOS 12 or later" or similar
    - If that dialog appears, the LSMinimumSystemVersion is still 12.0 — report immediately as a FAIL

    Windows VM:
    1. Transfer NSIS installer or portable .exe to the VM via shared folder or Drive
    2. Double-click the installer / portable exe
    3. EXPECTED: SmartScreen shows "Windows protected your PC" — this is expected for unsigned apps
    4. Click "More info" → click "Run anyway"
    5. EXPECTED: Installer opens (NSIS) OR app opens directly (portable)
    6. Complete installation if using NSIS, then launch Mrs. Proper
    7. Telegram login screen appears → enter any phone number → tap "Send code"
    8. EXPECTED: Login code input screen appears
    9. Close/quit the app

    If anything fails:
    - Hard launch failure (crash, blank screen, "requires macOS 12", "app is damaged"): report as FAIL with machine + OS version + error message
    - Telegram login does not reach code-entry step: report as FAIL — embedded credentials may not be substituted correctly in the packaged build
    - Gatekeeper hard block on macOS (cannot be opened): report as FAIL — notarization may not have propagated to Gatekeeper CDN (wait ~15 min and retry, or check Apple status page)
    - SmartScreen hard block on Windows (no "Run anyway" option): report as FAIL — this indicates the executable is flagged; unlikely for a fresh binary
  </how-to-verify>
  <resume-signal>
    Report each machine result:
    - ARM Mac: pass / fail (+ details if fail)
    - Intel Mac: pass / fail (+ details if fail)
    - Big Sur Mac (11.7.10): pass / fail (+ details if fail) — THIS IS THE CRITICAL ONE
    - Windows VM: pass / fail (+ details if fail)

    Type "UAT passed" only if all four machines reach the Telegram code-entry step.
    Type "UAT partial: [machine] failed: [error]" if one or more machines did not pass.
    Type "UAT failed: [summary]" if the primary machine (Big Sur) or majority failed.

    After all passes: type "approved — ready to distribute 0.9.0 RC".
    After UAT confirms all clean: bump version to 1.0.0 and create a git tag (handled in a follow-up quick task, not this phase).
  </resume-signal>
</task>

| release/dist/ artifacts → end-user machines | Files transferred via Drive/Telegram/USB; quarantine xattr simulates real-world download Gatekeeper check |
