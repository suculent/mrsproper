    - setStatus(status, completedAt?): updates _currentJob.status (and completedAt if provided), re-writes atomically

    - clearJob(): sets _currentJob to null; deletes the file if it exists
    - getRemaining(): returns dialogIds whose id is not present in any outcomes.dialogId
    - 0o600 mode: writeFileSync is called with { mode: 0o600 } on every write
    - Lazy requires: all require('node:fs') and require('electron') calls are inside method bodies or resolveFs()/resolveApp() helpers — NOT at module scope
