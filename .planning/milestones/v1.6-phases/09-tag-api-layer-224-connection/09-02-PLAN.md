<objective>
Build the isolated layer-224 `TagClient` wrapper that performs patch-connect-restore of
`AllTLObjects.LAYER` and routes all invokes through the shared `RateLimitGovernor`. This is
the only place in the codebase where the LAYER global is mutated — it is tightly scoped and
immediately restored after connect resolves, so the main layer-198 client is never affected.

Purpose: The `TagExecutor` (Phase 11) constructs a `TagClient` at the start of a tag run and
calls `tagClient.invoke(makeEditChatParticipantRankRequest(...))` through the governor. This
plan delivers that module, fully unit-testable without a live Telegram connection.

Output: `src/main/telegram/tagClient.ts` (class + options type) and
`src/main/telegram/tagClient.test.ts` (layer-restore, governor-routing, teardown assertions).
</objective>

    ```typescript
    export interface TagClientInner {
      connect(): Promise<void>
      disconnect(): Promise<void>
      invoke(request: unknown): Promise<unknown>
    }

    export interface TagClientOptions {
      /** Injectable inner TelegramClient (real or mock). */
      inner: TagClientInner
      /** Shared account-wide RateLimitGovernor — all invokes MUST route through it. */
      governor: RateLimitGovernor
    }

    export class TagClient {
      private readonly _inner: TagClientInner
      private readonly _governor: RateLimitGovernor
      private _connecting = false

      constructor(options: TagClientOptions)

      /**
       * Connect the inner client at layer 224 using patch-connect-restore.
       *
       * Guard: throws TagClientError('already-connecting') if called while a prior
       * connect() is in flight — prevents double-connection and double LAYER mutation.
       *
       * Patch-connect-restore (LOCKED — proven by Phase 0 spike):
       *   1. allTl.LAYER = 224
       *   2. await this._inner.connect()   ← server handshake at 224
       *   3. allTl.LAYER = 198             ← restore IMMEDIATELY, in finally block
       *
       * The finally block ensures LAYER is always restored even if connect() throws.
       */
      async connect(): Promise<void>

      /**
       * Invoke a request through the shared governor.
       * ALL tag writes MUST pass through governor.run() — never call _inner.invoke() directly.
       * Write-only: do NOT pass getDialogs/getParticipants requests here.
       */
      async invoke(request: unknown): Promise<unknown>

      /** Disconnect and tear down the inner client. */
      async disconnect(): Promise<void>
    }
    ```

    Implementation notes:
    - `_connecting` flag: set to true before the LAYER patch, cleared in the finally block after restoring LAYER. Throw a plain Error with message 'TagClient: connect() already in progress' if called while `_connecting` is true.
    - `connect()` body:
      ```
      if (this._connecting) throw new Error('TagClient: connect() already in progress')
      this._connecting = true
      const allTl: { LAYER: number } = require('telegram/tl/AllTLObjects')
      const prevLayer = allTl.LAYER  // should be 198; captured for safety
      try {
        allTl.LAYER = 224
        await this._inner.connect()
      } finally {
        allTl.LAYER = prevLayer   // restore to whatever it was (always 198 in production)
        this._connecting = false
      }
      ```
    - `invoke()` body:

      return this._governor.run(() => this._inner.invoke(request))
      ```
    - `disconnect()` body:

      await this._inner.disconnect()
      ```
    - Import `RateLimitGovernor` type from './governor'. Do NOT import the full governor module if only the type is needed — use `import type` to keep this module testable without side effects.
