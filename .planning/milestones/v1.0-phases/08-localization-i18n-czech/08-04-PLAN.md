<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → main (LANGUAGE_SET / THEME_SET) | Language/theme values sent via IPC; Zod validates in main (Plan 02) |
| OS locale detection | navigator.language used pre-mount; untrusted but benign (maps to 'en'/'cs' only) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06 | Spoofing | navigator.language OS locale detection | accept | Only distinguishes cs vs non-cs; cannot inject arbitrary i18n keys; worst case wrong default language on first launch |
| T-08-07 | Tampering | SettingsMenu language/theme selection | mitigate | Values sent via setLanguage/setTheme go through Zod validation in main (T-08-01/T-08-02 per Plan 02) |
| T-08-08 | Denial of Service | IPC failure in pre-mount | mitigate | Both window.mrsproper.getLanguage().catch(() => null) and getTheme().catch(() => null) — IPC failure falls back to OS detection; app always mounts |
</threat_model>
