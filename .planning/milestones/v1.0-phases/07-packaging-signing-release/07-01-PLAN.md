Downgrade Electron from ^42.0.0 to the exact pin 37.10.3 — the last Electron major whose bundled app carries LSMinimumSystemVersion: 11.0 (Big Sur). This is a prerequisite for all packaging work: no build, sign, or notarize task can proceed until the correct Electron binary is installed.

Research confirmed zero code changes are needed — all Electron APIs used by this app exist identically in Electron 37 types (verified by grep on installed electron@37.10.3 electron.d.ts). The EOL status (January 13, 2026) is a known accepted tradeoff documented in the release notes.

Output: package.json with "electron": "37.10.3" (exact pin, no caret), node_modules rebuilt with 37 binaries, vitest green, tsc green.
