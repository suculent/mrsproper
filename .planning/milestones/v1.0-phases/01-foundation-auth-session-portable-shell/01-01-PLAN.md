<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build env → committed source | api_id/api_hash injected at build time must not land in git |
| main bundle → renderer bundle | credentials must compile into main only; renderer is least-trusted |
| renderer → OS/network | renderer may only load the local bundle (no remote content) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | api_id/api_hash in committed source | mitigate | Build-time `define` from untracked `.env`; `.env` gitignored; automated 32-hex grep guard over tracked files (Task 2 verify) |
| T-01-02 | Information Disclosure / Elevation | credentials leaking into renderer bundle | mitigate | `define` injected into MAIN vite section only; automated check fails build if MRPROPER_API_HASH appears in renderer section; renderer console check in Task 3 |
| T-01-03 | Elevation of Privilege | renderer gains Node/full-API access | mitigate | `contextIsolation:true`, `nodeIntegration:false`, `sandbox:true` on the BrowserWindow (Task 1) |
| T-01-04 | Tampering | remote content / SSRF in renderer | mitigate | CSP allows local bundle only; offline Inter via `@fontsource/inter`; no CDN/remote URLs |
| T-01-SC | Tampering | npm installs (supply chain) | mitigate | Core packages are official/well-known (RESEARCH Package Legitimacy Audit, all Approved); [ASSUMED] libphonenumber-js/zod are NOT installed in this plan (gated in plan 02); `telegram` has no postinstall script (verified) |
</threat_model>
