    run<T>(fn: () => Promise<T>): Promise<T> implementation:
    - Chains fn onto _tail to enforce serialization (concurrency=1, EXE-01)
    - _tail = _tail.then(() => this._executeWithPolicy(fn)).then(() => {}, () => {})
    - Returns the result promise directly (not _tail)

    _executeWithPolicy<T>(fn: () => Promise<T>) private async method — the retry/FLOOD_WAIT loop:
    - Constants: MAX_TRANSIENT_RETRIES = 3, FLOOD_CEILING_S = 3600
    - BACKOFF_BASE_MS = [1000, 2000, 4000] (D-14 exponential backoff)
    - Loop variable: transientAttempts = 0
    - while(true) loop calling fn():
      - On success: return result
      - On error: call classifyRpcError(err) to get classified
      - If disposition === 'hard-stop': emit { type: 'hard-stop', code: classified.code } via _onEvent; throw err (propagate — Phase 5 handles job abort)
      - If disposition === 'wait':
        - seconds = classified.retryAfterSeconds ?? 0
        - If seconds > FLOOD_CEILING_S: emit { type: 'wait-too-long', seconds }; throw err (D-12)
        - Emit countdown via this._floodController.start(seconds, tick => _onEvent({ type: 'flood-tick', remaining: tick.remaining }), onDone)
        - Sleep for seconds duration PLUS additive jitter (D-10): J = Math.min(Math.max(0.1 * seconds, 1), 5); totalMs = (seconds + Math.random() * J) * 1000; await new Promise(resolve => globalThis.setTimeout(resolve, totalMs))
        - After sleep: stop the flood controller (this._floodController.stop())
        - Continue loop (retry same fn — D-10 says not counted against transient budget)
      - If disposition === 'retry':
        - If transientAttempts >= MAX_TRANSIENT_RETRIES: throw err
        - Emit { type: 'retry-attempt', attempt: transientAttempts + 1, maxAttempts: MAX_TRANSIENT_RETRIES }
        - Sleep BACKOFF_BASE_MS[transientAttempts] + Math.random() * 500 ms
        - Increment transientAttempts; continue loop
      - Else (fail, skip, unknown): throw err

    Constructor:
    constructor(options: GovernorOptions) {
      this._client = options.client
      this._onEvent = options.onEvent ?? (() => {})
      this._floodController = new FloodWaitController(options.timingSource)
    }
