    Adding `SESSION_REVOKED` is safe — `makeRPCError` handles all string literals identically (sets `err.errorMessage = code`). No changes to `makeRPCError` are needed.

    The `logoutError` field (line 65) currently accepts a plain `Error`. Replace it with a typed `logoutErrorCode` field using the extended `MockRPCErrorCode` union:
    - Remove the `logoutError?: Error` field.
    - Add `logoutErrorCode?: MockRPCErrorCode`.

    In the `invoke()` handler, LogOut branch (lines 127-130):
    - Change `if (config.logoutError) { throw config.logoutError }` to `if (config.logoutErrorCode) { throw makeRPCError(config.logoutErrorCode) }`.

    - Test "logout server fail: after wipe, manager state is idle" (line 89): Change `logoutError: new Error('SERVER_FAIL')` to `logoutErrorCode: 'SESSION_REVOKED'` (same rationale — non-retryable, immediate throw).
