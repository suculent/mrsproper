# Phase 4.1 Plan 04: searchClient + searchStore + TargetInput Name Mode Summary

**One-liner:** renderer IPC client and useSyncExternalStore search store wired; TargetInput extended with name mode detection dispatching to searchActions.startSearch with 2-char guard

## What Was Built

**searchClient.ts:** Augments `MrsProperApi` via `declare global { interface MrsProperApi { ... } }` with 5 name search methods (`startSearch`, `abortSearch`, `getSearchState`, `onSearchState`, `selectCandidate`). Exports `searchClient` object with `window.mrsproper.*` call implementations. Exact analog of `groupsClient.ts`.

**searchStore.ts:** Module-level `currentState: SearchState = { step: 'idle' }` with ref-counted subscription lifecycle (`startSubscriptions`/`stopSubscriptions`). Single `onSearchState` subscription (simpler than groupsStore — no `_prevScanStep`, no checkedDialogIds). Exports `useSearchStore()` hook via `useSyncExternalStore` and `searchActions` with `startSearch`, `abortSearch`, `selectCandidate` dispatchers. Exact analog of `groupsStore.ts` minus the pre-check rebuild complexity.

**TargetInput.tsx (surgical edits):**
- `InputMode` extended to include `'name'`
- `detectMode()` reordered: phone-bare check moved before the name rule; name rule (`/\s/.test || !/^[a-zA-Z0-9_]+$/.test`) inserted before username branch (UI-SPEC rule 4)
- `User` icon imported from `lucide-react`; `useSearchStore` and `searchActions` imported from `@renderer/store/searchStore`
- `isNameMode` and `isNameSearchRunning` derived in component body
- Name mode chip: `<User h-3.5 w-3.5> + <span>Name</span>` in right-edge muted style
- Name-mode hint line renders when `isNameMode` (same slot as phone hint)
- Sr-only aria-live includes `'Name search mode detected'` branch
- `handleSubmit` name mode branch: trims normalized, guards `< 2 chars`, calls `searchActions.startSearch(trimmed)`, returns — never reaches `targetActions.resolveTarget()`
- `isFindDisabled` includes `|| isNameSearchRunning`

**resolveCopy.ts:** `TARGET_USERNAME_NOT_FOUND` gains trailing hint: `"…If you only know their name, type it with a space to search your groups by name."`
