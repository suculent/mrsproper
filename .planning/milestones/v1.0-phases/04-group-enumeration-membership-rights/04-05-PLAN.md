## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → main (scan:retryGroup) | dialogId must be validated against known in-memory list before reaching scanner |
| renderer → main (scan:start) | No payload accepted — target comes from main-side TargetResolver only |
| main → renderer (state push) | All push calls gated on !win.isDestroyed() |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Tampering | scan:retryGroup IPC handler | mitigate | dialogId validated with Zod (string 1–32 chars) then cross-checked against enumerator's in-memory dialog list — unknown IDs rejected before any API call |
| T-04-07 | Tampering | scan:start IPC handler | mitigate | Handler accepts no payload; MembershipScanner reads target from TargetResolver in main process — renderer cannot inject a different target ID |
| T-04-08 | DoS | win.webContents.send (state push) | mitigate | All emitGroupsState/emitScanState calls check !win.isDestroyed() (RESEARCH Pitfall 6) |
| T-04-SC | Tampering | @radix-ui packages (installed in plan 06) | mitigate | Package legitimacy audit in RESEARCH.md shows [OK] for both — blocking checkpoint not required |
</threat_model>
